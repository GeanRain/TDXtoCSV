# 通达信 DLL 多线程异步保存设计方案

## 总体结构

通达信 → SaveAsCSV.dll → 本机命名管道 → SaveAsCSVWorker.exe → CSV。

- 通达信依次执行每个品种、每个周期的完整公式。
- DLL 接收当前品种的数据，通过管道交给独立的 32 位后台程序。
- 后台持有内存队列，使用固定数量的保存线程完成校验、CSV 合并和写入。

DLL 与后台程序放在同一个解决方案内，共用数据协议和 CSV 保存代码。

两个工程的 Release / x86 发布版均使用 C++17 和 `/MT`，将 C++ 运行库编入各自模块，避免受宿主或系统中旧运行库影响。跨模块仅传递公式参数及管道数据，内存由分配它的模块释放。

## 数据流程

1. DLL 开始一次采集，核对代码、市场、周期和配置，并向后台预留任务额度；空间不足时等待。
2. 按公式顺序复制日期、时间和六组行情数组，检查指针、条数及调用顺序。
3. 最后一次保存调用通过管道发送完整任务。后台收齐数据、核对完整性并入队后才确认成功。
4. DLL 收到确认后释放当前数据，通达信继续处理下一个品种。短暂断线时先核实原任务是否接收，避免重复提交；无法确认时明确返回失败。
5. 后台线程取得任务，校验日期、时间、数据升序及行情数值，再读取并校验旧 CSV。
6. 按现有规则合并；最终内容与原文件完全一致时跳过 CSV 写盘，任务仍按成功统计。有变化时写入同目录临时文件，完成检查和刷盘后替换目标 CSV。
7. 记录结果、释放任务及临时内存，归还额度并唤醒等待者。

提交成功只表示后台已完整接收，保存结果通过日志、查询接口和排空接口确认。

## 队列与并发

队列容量由 `queue_capacity` 和 `queue_memory_mb` 共同限制，默认 1000 个任务、2048 MiB 任务数据。额度包含采集预留、等待任务和正在保存的任务；任务完成并释放资源后才归还。

任一额度不足时，DLL 每 200 毫秒重新检查，允许阻塞直到有空间。实际 C++ 内存分配失败也按此间隔重试，前台可通过停止接口中断等待。任务数据额度不代表后台总内存，旧 CSV 解析和合并仍需要临时空间。

保存线程通过 `worker_threads` 配置，默认 8 个、范围 1—128。线程重复使用，空闲时等待；不同 CSV 可以并行，同一个 CSV 按提交顺序串行。

## 文件保护与异常

- 校验和合并规则由 DLL 工程与后台工程共用，不因异步提交而省略。
- 写锁覆盖旧文件读取、合并及替换全过程；输入或文件校验失败时保留原 CSV。
- 保存失败记录错误并释放该任务额度，后续任务继续处理。内存分配失败则清理本次临时资源后重试。
- 数据只在内存中排队，没有磁盘恢复队列；后台被结束或关机后，未完成任务丢失。

## 启停与状态

后台在通达信绑定 DLL、注册函数表时自动启动；主动排空停机后，再次导出会按需启动。程序路径使用相对于 DLL 的 `worker_path`，配置、日志和 CSV 相对路径始终以 DLL 所在目录为基准。

6 号接口查询负载及错误；7 号停止接收、等待已提交任务完成并停止后台；8 号停止新增输入并唤醒等待者。DLL 卸载或重新注册接口时直接结束旧后台，丢弃未完成任务，重新绑定使用新后台及新统计。

DLL 持有一个 Windows 作业对象句柄，用于统一管理后台进程；关闭该句柄时系统自动终止关联进程。启动时使用 Windows 10/11 的 `PROC_THREAD_ATTRIBUTE_JOB_LIST`，在创建进程的同一次系统操作中加入作业对象，避免宿主恰好退出时留下未受管理的后台。句柄不传给后台，宿主异常退出也会触发关闭。

DLL 装载入口只建立生命周期句柄，卸载入口只关闭句柄并释放本地代理，不等待队列或管道；创建进程及握手放在函数注册阶段，避开 DLL 装卸锁。每次重新装载或注册都更换管道标识，并清除旧线程采集状态，避免连接旧后台或释放新后台的预留。

后台监视通达信进程。通达信正常退出或崩溃时，后台立即退出，不等待队列及正在保存的任务。已保存的 CSV 保留，尚未完成的任务丢弃；需要全部完成时，先运行 7 号排空再退出。

CSV 目录中的 `_bg_` 状态文件展示等待数、运行数及上限，有任务时每 5 秒更新，空闲后固定更新一次。它不代替保存结果检查。

## 相关文件

- `SaveAsCSV/link/tdx/linkTDX.cpp`：通达信接口与当前品种采集。

- `SaveAsCSVWorker/main.cpp`：后台入口和宿主监视。
- `SaveAsCSV/export/async_writer.*`：队列、额度及保存线程。
- `shared/ipc.*`、`shared/csv_store.*`：通信协议及 CSV 校验、合并、文件保护。
